# بصمة الشمراني

نظام حضور وانصراف لشركة سعد مفرح الشمراني للاستشارات الهندسية. يشتغل كتطبيق على الجوال، والبيانات محفوظة أونلاين على Firebase.

## المميزات

- بصمة الوجه والإصبع، والموظف يدخل باسم مستخدم (حروف عربي أو إنجليزي وأرقام).
- الأقسام: المساحة، المعماري، الإنشائي، السلامة، الثلاثي الأبعاد، المحاسب، الإشراف.
- صلاحية مكان التسجيل لكل موظف: من مواقع محددة، أو من أي مكان.
- صفحة «موقعي المباشر» للموظف، وخريطة مباشرة للمالك عليها كل الموظفين ومسار حركتهم.
- شات داخلي لكل الموظفين والمالك، من غير ردود آلية.
- تنبيهات للموظف: الحضور من أول دقيقة، وبعد ٥ دقائق، وموعد البريك، والعودة، والانصراف.
- مواعيد العمل وفترة السماح يغيّرها المالك بس، في أي وقت.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | واجهة التطبيق |
| `app.js` | منطق التطبيق والاتصال بـ Firebase |
| `config.js` | إعدادات مشروع Firebase ورقم المالك |
| `firestore.rules` | قواعد الحماية، تُلصق في Firebase وليس لها دور على GitHub |
| `manifest.json` و`sw.js` | التثبيت على الجوال والعمل بدون إنترنت |
| `logo-*.png` و`mark.png` و`logo-full.png` و`badge-96.png` | اللوجو وأيقونة الهوم سكرين |

## الإعداد مرة واحدة

1. **مشروع Firebase جديد:** من [console.firebase.google.com](https://console.firebase.google.com) اعمل مشروع جديد، مثلاً `shamrani-basma`.
2. **تسجيل الدخول:** ادخل **Authentication**، ثم **Get started**، وفعّل **Email/Password**.
3. **قاعدة البيانات:** ادخل **Firestore Database**، ثم **Create database**، واختار أقرب منطقة (مثلاً `me-central2` الدمام).
4. **حساب المالك:** في **Authentication** ثم **Users** دوس **Add user**، واكتب إيميلك وكلمة سر. انسخ الـ **User UID** اللي هيظهر.
5. **إعدادات التطبيق:** من **Project settings** ثم **Your apps** اضغط أيقونة الويب `</>` وسجّل التطبيق. انسخ قيم `firebaseConfig` والصقها في `config.js`، والصق الـ UID مكان `PASTE_OWNER_UID`.
6. **قواعد الحماية:** افتح `firestore.rules`، وغيّر `PASTE_OWNER_UID` لنفس الـ UID. في Firebase ادخل **Firestore** ثم تبويب **Rules**، امسح الموجود والصق المحتوى كله، ودوس **Publish**.
7. **الرفع:** ارفع كل الملفات على GitHub في أول الـ Repository من غير فولدرات، وفعّل **GitHub Pages**.
8. **الدومين:** في Firebase ادخل **Authentication** ثم **Settings** ثم **Authorized domains**، وأضف دومين GitHub Pages (مثلاً `alfayz-co.github.io`).

## الاستخدام

- **المالك:** يدخل بالإيميل. من الرئيسية يضيف الموظفين ويحدد قسم كل واحد. من الإعدادات يحدد مواعيد العمل وفترة السماح ومواقع العمل. ومن صفحة كل موظف يحدد صلاحية مكان التسجيل.
- **الموظف:** يدخل باسم المستخدم وكلمة السر المؤقتة، ويُطلب منه تغييرها. أول بصمة إصبع تربط جواله بحسابه.

## حدود لازم تعرفها

- **الإشعارات** بتوصل والتطبيق مفتوح أو في الخلفية. لو التطبيق مقفول خالص، الإشعار مش هيوصل. ده محتاج Firebase Cloud Messaging مع Cloud Functions، وده على خطة Blaze المدفوعة.
- **الموقع المباشر** بيشتغل طول ما التطبيق مفتوح على شاشة الموظف. الجوال (خصوصاً الآيفون) بيوقف الموقع لما التطبيق يتقفل أو الشاشة تطفى. التطبيق بيحاول يخلّي الشاشة شغالة أثناء المشاركة، وبيرجع يشغّل المشاركة لوحده لما الموظف يفتحه تاني.

## التحديث

عند رفع نسخة جديدة، غيّر رقم `CACHE` في `sw.js`، مثلاً `shamrani-basma-v2`.
